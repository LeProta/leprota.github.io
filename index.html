Le Journal Financier rassemble des articles économiques et financiers sourcés, à lire directement dans l’application. Une édition PDF reste disponible. Son composant « Journal Financier - archivage » conserve les éditions dans le Google Drive de son propriétaire.

Application à usage personnel

Préparer, conserver, lire.

Le projet organise la collecte de sources, la rédaction et les contrôles d’une édition. Selon sa configuration privée, une rubrique pédagogique peut s’appuyer sur des supports de cours autorisés et proposer des exercices.

Après validation, l’édition est déposée dans un dossier Drive dédié. Chaque PDF daté reste archivé ; une copie courante conserve le même lien pour retrouver la dernière édition disponible.

Pourquoi connecter Google ?

L’autorisation Google permet au composant d’archivage de créer et de gérer les fichiers qu’il utilise pour cette fonction : PDF, copie courante et métadonnées de vérification.

La permission demandée est drive.file. Elle porte sur les fichiers créés ou explicitement autorisés pour cette application.

Les documents restent privés.

Ce site présente le fonctionnement de l’application et son utilisation des données Google. Les journaux et les supports pédagogiques sont conservés dans les espaces privés configurés par le propriétaire, avec leurs propres autorisations d’accès.

Le dépôt et les notifications peuvent être exécutés sur GitHub. Les notifications Web Push préviennent de la disponibilité d’une édition. Les fonctions de rédaction et de relecture, si elles sont activées, utilisent le fournisseur d’IA choisi dans la configuration privée du projet.
