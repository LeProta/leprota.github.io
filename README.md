# Le Journal Financier — pages publiques de présentation

Pages statiques de présentation du composant personnel « Journal Financier - archivage » et de son utilisation de Google Drive. Elles sont destinées aux liens de présentation et de confidentialité de Google Auth Platform.

Ce dépôt contient uniquement les pages publiques, leur style et leur icône. Le code du journal, les cours, les PDF, les identifiants et les paramètres de connexion restent dans leurs espaces privés.

- `index.html` : présentation de l’application.
- `confidentialite.html` : politique de confidentialité spécifique au fonctionnement du projet.
- `styles.css` et `favicon.svg` : présentation sans ressources externes.
- `.nojekyll` : publication statique directe avec GitHub Pages.

Une balise ou un fichier de vérification Google pourra être ajouté à la demande de la Search Console. Il doit provenir du compte propriétaire et ne doit jamais être inventé.
